## Week 3 Assignment: Create a Multi-Page Static Website for a Small College

### Overview
In this assignment, you will design and develop a **responsive static website** for a fictional small college. The website should look professional, follow web design best practices, and function and display properly across the different device screen sizes (mobile, tablet, and desktop). You can resize the browser to check the responsiveness. The site will be built using **HTML and CSS only**—no other frameworks (such as Bootstrap, Tailwind, or JavaScript) are allowed.  The images and style sheets should be stored in their respective directories.  The project MUST have external CSS style sheets.  

### Requirements
- A **main homepage** introducing the fictional college.  
- **Three additional pages** commonly found on college websites, such as:  
  - About the College  
  - Admissions  
  - Academics (Programs/Majors)  
  - Student Life  
  - Faculty/Staff Directory  

- The entire site must:  
  - Be fully functional as a static site (HTML + CSS).   
  - Be **responsive** and correctly display on phone, tablet, and desktop.  
  - Use **plain CSS** (no preprocessors, CSS frameworks, or JavaScript libraries).  
  - Follow **web design best practices** (see below).  

### Web Design Best Practices
The five most important design best practices you must apply are:  

1. **Consistent Layout and Navigation**  
   - The navigation bar should appear in the same position on every page.  
   - Color scheme, fonts, and design elements should remain consistent.   

2. **Responsiveness and Accessibility**  
   - Pages should adapt smoothly to different screen sizes.  
   - Text must be readable without zooming.  
   - Use semantic HTML elements for screen-reader accessibility.  

3. **Visual Hierarchy and Readability**  
   - Use headings, subheadings, and whitespace effectively.  
   - Body text should be easy to read with appropriate font size and spacing.  
   - Images and graphics should support content, not distract.  

4. **Optimized Media and Performance**  
   - Images should be compressed for web use to avoid slow load times.  
   - Avoid overly large files or unnecessary elements.  

5. **Clear Purpose and User-Centered Design**  
   - Each page should communicate its purpose clearly.  
   - Information should be easy to find, with logical page structure and intuitive links.
